### نظرة عامة
تعتبر أدوات K-HUB حزمة إنتاجية شاملة لBlender، مصممة لتبسيط سير العمل في الإظهار المعماري، وتصميم البيئات، . تدمج هذه الحزمة العديد من الأدوات   في واجهة واحدة منظمة ومرتبة بشكل احترافي .

### المميزات الجديدة V2.0 :
- **دعم Blender 5.3**: تم تحسينه واختباره بالكامل ليعمل مع Blender 5.3، بما في ذلك تحسينات الواجهة وتوافق الـ API.
- **إضافة أدوات التحكم في الـ HDRI**: أدوات متقدمة للتحكم الكامل في إعدادات الإضاءة البيئية HDRI.
- **تحسين أدوات الكاميرا**: تحسينات جذرية على أدوات إدارة الكاميرا مع إضافة ميزات جديدة.

### المميزات الرئيسية

#### 1. نظام التوزيع (K-HUB Scatter) :
- توزيع الكائنات بكفاءة على الأسطح باستخدام "Geometry Nodes" أو أنظمة الجسيمات "Particle Systems".
- العرض الافتراضي مضبوط على **BOUNDS** (الصناديق المحيطة) لتحسين أداء واجهة العرض.
- زر تبديل سهل الاستخدام للتحويل بين نمط الأداء ونمط التفاصيل الكاملة.
- إعدادات مسبقة متخصصة للعشب، الأوراق، اللبلاب، والصخور.

#### 2. مدير الكاميرات
- إدارة الكاميرات المتعددة بسهولة داخل المشهد.
- وصول سريع لإعدادات الكاميرا والبعد البؤري.

#### 3. مدير الإضاءة و Light Mix :
- تحكم مركزي لجميع الأضواء في المشهد.
- دعم **Light Mix** لتعديل شدات وألوان مجموعات الإضاءة بعد الرندر (مشابه لـ Corona/V-Ray).
- دعم إعدادات إضاءة HDRI و Dome.

#### 4. صانع ومدير الأصول (Assets) :
- تمييز وتنظيم الكائنات كأصول (Assets) بسرعة.
- سير عمل مبسط لاستيراد وإدارة الأصول عبر المشاريع المختلفة.

#### 5. إعدادات الذاكرة والرندر :
- إعدادات رندر مسبقة ومحسنة لتحقيق التوازن بين الجودة والسرعة.
- وصول سريع لإعدادات محرك Cycles.
- ادوات تحسين الذاكرة.

#### 6. أدوات استيراد SketchUp :
- أدوات متقدمة لاستيراد وتحسين نماذج SketchUp لتناسب Blender.
- دعم السحب والإفلات لملفات `.skp`.

#### 7. أدوات المواد (Materials)
- أدوات إدارة المواد والتعيين السريع.
-  مكتبة مواد اساسية جاهزة.


#### - طريقة التثبيت :
1. قم بتحميل الادون بصيغة ZIP.
2. في Blender، انتقل إلى `Edit > Preferences > Add-ons > Install`.
3. اختر ملف ZIP الذي حملته.
4. قم بتفعيل `KH-Tools` من القائمة.

### Title
K-HUB Addon

A free Blender addon designed to streamline the architectural visualization (ArchViz) workflow.

### Buttons

### Overview
K-HUB is a comprehensive productivity suite for Blender, engineered to simplify workflows in architectural visualization and environment design. This package integrates numerous tools into a single, professionally organized interface.

### New Features V2.0
- **Blender 5.3 Support**: Fully optimized and tested for Blender 5.3, including UI enhancements and API compatibility.
- **HDRI Control Tools**: Advanced tools for complete control over HDRI environment lighting settings.
- **Camera Tools Enhancement**: Major improvements to camera management tools with new added features.   

### Main Features

#### 1. Distribution System (K-HUB Scatter)
- Efficiently scatter objects on surfaces using Geometry Nodes or Particle Systems.
- Default display set to BOUNDS to maintain high viewport performance.
- Easy toggle switch to flip between "Performance Mode" and "Full Detail Mode."
- Specialized presets for grass, leaves, ivy, and rocks.

#### 2. Camera Manager
- Easily manage multiple cameras within a single scene.
- Quick access to camera settings and focal lengths.

#### 3. Lighting Manager & Light Mix
- Centralized control for all scene lights.
- Light Mix Support: Adjust intensities and colors of light groups post-render (similar to Corona/V-Ray).
- Integrated support for HDRI and Dome light setups.

#### 4. Asset Creator & Manager
- Quickly mark and organize objects as assets.
- Streamlined workflow for importing and managing assets across different projects.

#### 5. Memory & Render Settings
- Optimized render presets to balance quality and speed.
- Quick-access settings for the Cycles engine.
- Integrated memory optimization tools.

#### 6. SketchUp Import Tools
- Advanced tools for importing and optimizing SketchUp models for Blender.
- Drag-and-drop support for .skp files.

#### 7. Material Tools
- Material management and quick-assignment tools.
- Includes a library of essential ready-to-use materials.

### Installation
1. Download the addon as a ZIP.
2. In Blender, go to `Edit > Preferences > Add-ons > Install`.
3. Select the ZIP file.
3. Enable `K-HUB` from the list.
