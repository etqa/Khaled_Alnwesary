## العربية (Arabic)

### Title
متصفح مكتبة بلندر

### Short Description
برنامج سطح مكتب لتصفح وإدارة مكتبة أصول Blender الخاصة بك مع السحب والإفلات المباشر، الفهرسة التلقائية، والتكامل مع Poly Haven وBlenderKit وambientCG.

### الأزرار
- [تحميل التطبيق][dl_app]
- [دعم المطور][wa_support]

### نظرة عامة
برنامج سطح مكتب متقدم (Electron) يعرض مكتبة بلندر بتاعتك من أصول .blend ومجسمات وخامات وHDRI بطريقة احترافية. يدعم الفلترة المتقدمة والكاتيقريات والتاقات والصور المصغرة، مع إمكانية سحب العنصر وإفلاته داخل نافذة بلندر مباشرة دون فتح Asset Browser.

### المميزات الرئيسية

#### 1. تصفح شامل للأصول
- قراءة مباشرة لملفات .blend (بلندر 2.9 حتى 5.x) بدون الحاجة لتشغيل بلندر
- دعم جميع أنواع الأصول: Objects, Materials, Collections, Worlds, Node Groups, Actions
- دعم ملفات المجسمات: FBX, OBJ, GLB, GLTF, STL, PLY, USD, ABC, DAE, SKP, MAX, C4D
- دعم صور HDRI (HDR/EXR) والخامات الصورية (PNG/JPG/TIF)
- فهرسة تزايدية ذكية لعشرات الآلاف من الملفات

#### 2. السحب والإفلات المباشر
- اسحب أي عنصر وأفلته في 3D Viewport ليُضاف تحت المؤشر مباشرة
- تحديد متعدد ودفعة واحدة مع مصفوفة تلقائية
- معاينة إطار حي (Bounding Box) أثناء السحب يتبع السطح
- دعم Append وLink للكوليكشنات والخامات
- إضافة الخامات بالإفلات المباشر على المجسمات

#### 3. مكتبات أونلاين متكاملة
- **Poly Haven**: تصفح وتنزيل HDRIs وTextures وModels مباشرة (CC0)
- **BlenderKit**: تسجيل دخول وتنزيل الأصول المجانية والمدفوعة
- **ambientCG**: خامات وHDRI ونماذج وملصقات (CC0)
- تحويل تلقائي للتنزيلات إلى أصول جاهزة للاستخدام
- حفظ المفضلة والتنزيل المتعدد المتوازي

#### 4. أدوات ذكاء اصطناعي مدمجة
- **رفع دقة الصور** (Real-ESRGAN): تحسين جودة الصور حتى ×4 أوفلاين
- رندر Cycles للصور المصغرة بجودة عالية

#### 5. إدارة متقدمة
- تنظيم بالكاتالوجات (Blender Catalogs) أو المجلدات
- إنشاء وتعديل ونقل الكاتالوجات مباشرة
- نظام مفضلة متطور مع مجلدات مخصصة
- فلترة وبحث قوي عبر الاسم والتاق والكاتيقري
- توليد وحفظ الصور المصغرة داخل ملفات .blend

### التثبيت والإعداد

#### المتطلبات
- Windows 10/11 (يعمل على Linux/macOS)
- Node.js 20 أو أحدث (للتطوير)
- Blender 4.2 أو أحدث (للإضافة)

#### خطوات الإعداد (3 خطوات)
1. **Settings → Blender executable → Detect** لاكتشاف مسار بلندر تلقائياً
2. **Settings → Install add-on** لتثبيت إضافة Asset Browser Bridge في بلندر
3. اضغط **+** في Libraries واختر مجلد المكتبة لبدء الفحص

### المميزات الإضافية

#### واجهة مستخدم متقدمة
- دعم كامل للغة العربية (RTL) والإنجليزية
- وضع فاتح وغامق مع متابعة النظام
- لوحات قابلة للطي والتوسيع
- تكبير/تصغير الواجهة (Ctrl + Mouse Wheel)
- عروض متعددة: شبكة، مصغرات فقط، قائمة

#### توليد الصور المصغرة
- رندر تلقائي بـ Workbench (سريع) أو Studio Lighting أو Cycles
- حفظ الصور داخل ملفات .blend للظهور في Asset Browser الأصلي
- قراءة صور المعاينة من ملفات .max وSKP
- دقة قابلة للتخصيص (256/512/768 بكسل)

#### تكامل مع برامج أخرى
- سحب ملفات SKP إلى SketchUp مباشرة
- إضافة Ruby plugin لـ SketchUp للتحكم الكامل
- Ctrl+سحب لنسخ الملف الحقيقي إلى Explorer أو برامج أخرى

### الدعم والتطوير
هذا التطبيق **مجاني تماماً** ومفتوح للجميع. إذا وجدت التطبيق مفيداً ويوفر عليك الوقت والجهد، يمكنك دعم المطور بشكل اختياري للمساعدة في تطوير المزيد من المميزات والتحديثات المستقبلية.

## English

### Title
Blender Library Browser

### Short Description
Desktop application for browsing and managing your Blender asset library with direct drag-and-drop, automatic indexing, and integration with Poly Haven, BlenderKit, and ambientCG.

### Buttons
- [Download App][dl_app]
- [Support Developer][wa_support]

### Overview
An advanced desktop application (Electron) that displays your Blender library of .blend assets, models, materials, and HDRIs in a professional way. Supports advanced filtering, categories, tags, and thumbnails, with the ability to drag and drop elements directly into Blender window without opening Asset Browser.

### Main Features

#### 1. Comprehensive Asset Browsing
- Direct reading of .blend files (Blender 2.9 to 5.x) without needing to run Blender
- Support for all asset types: Objects, Materials, Collections, Worlds, Node Groups, Actions
- Support for model files: FBX, OBJ, GLB, GLTF, STL, PLY, USD, ABC, DAE, SKP, MAX, C4D
- Support for HDRI images (HDR/EXR) and texture images (PNG/JPG/TIF)
- Smart incremental indexing for tens of thousands of files

#### 2. Direct Drag and Drop
- Drag any element and drop it in 3D Viewport to add it directly under cursor
- Multi-selection and batch import with automatic array
- Live bounding box preview while dragging that follows surface
- Support for Append and Link for collections and materials
- Add materials by dropping directly on objects

#### 3. Integrated Online Libraries
- **Poly Haven**: Browse and download HDRIs, Textures, and Models directly (CC0)
- **BlenderKit**: Sign in and download free and paid assets
- **ambientCG**: Materials, HDRIs, models, and decals (CC0)
- Automatic conversion of downloads to ready-to-use assets
- Save favorites and parallel multi-download

#### 4. Built-in AI Tools
- **Image Upscaling** (Real-ESRGAN): Improve image quality up to ×4 offline
- Cycles rendering for high-quality thumbnails

#### 5. Advanced Management
- Organization by Catalogs (Blender Catalogs) or Folders
- Create, edit, and move catalogs directly
- Advanced favorites system with custom folders
- Powerful filtering and search by name, tag, and category
- Generate and save thumbnails inside .blend files

### Installation and Setup

#### Requirements
- Windows 10/11 (works on Linux/macOS)
- Node.js 20 or newer (for development)
- Blender 4.2 or newer (for add-on)

#### Setup Steps (3 steps)
1. **Settings → Blender executable → Detect** to automatically detect Blender path
2. **Settings → Install add-on** to install Asset Browser Bridge add-on in Blender
3. Press **+** in Libraries and choose your library folder to start scanning

### Additional Features

#### Advanced User Interface
- Full support for Arabic (RTL) and English
- Light and dark mode with system follow
- Collapsible and expandable panels
- Zoom in/out interface (Ctrl + Mouse Wheel)
- Multiple views: grid, thumbnails only, list

#### Thumbnail Generation
- Automatic rendering with Workbench (fast) or Studio Lighting or Cycles
- Save images inside .blend files to appear in original Asset Browser
- Read preview images from .max and SKP files
- Customizable resolution (256/512/768 pixels)

#### Integration with Other Programs
- Drag SKP files to SketchUp directly
- Ruby plugin for SketchUp for full control
- Ctrl+drag to copy real file to Explorer or other programs

### Support and Development
This application is **completely free** and open to everyone. If you find the app useful and it saves you time and effort, you can optionally support the developer to help develop more features and future updates.
